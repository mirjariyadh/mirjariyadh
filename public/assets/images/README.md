# Project Images / ইমেজ ফোল্ডার

To add or update your images from Google Drive:
১. Google Drive থেকে আপনার ইমেজগুলো ডাউনলোড করুন।
২. সরাসরি এই `public/assets/images/` ফোল্ডারে অথবা `src/assets/images/` ফোল্ডারে পেস্ট করুন।
৩. নিচে উল্লেখিত ফাইলের নাম অনুযায়ী সংরক্ষণ করুন অথবা `src/data/portfolioData.ts` ফাইল থেকে নতুন ইমেজের নাম পয়েন্ট করে দিন:

### Standard Image File Names (ডিফল্ট ফাইলের নামসমূহ):
- `profile-mirja-riyadh.jpg` -> Mirja Riyadh Portfolio Avatar / Profile picture
- `project-arch-model.jpg` -> High-End Luxury Residential Architectural BIM Model
- `project-point-cloud.jpg` -> Heritage Commercial Scan-to-BIM Conversion
- `project-revit-family.jpg` -> Parametric Adaptive Facade Family Library
- `project-mep-clash.jpg` -> Multi-Story Hospital MEP & HVAC BIM Coordination
- `project-clash-tower.jpg` -> 500+ Clash Matrix Resolution for High-Rise Tower
- `project-2d-sheets.jpg` -> Permit-Ready Construction Documentation Set
- `hero-bg.jpg` -> Hero Section Background image

গিটহাবে পুশ (Push) করার পর GitHub Pages স্বয়ংক্রিয়ভাবে এই ইমেজগুলো লোড করে নিবে!
